# Zeda-8 迷你 ISA（一页纸）

教学用 8 位指令集草案；权威实现见 `src/features/cpu/lib/`。行为变更须走 OpenSpec change。

## 机器模型

| 项 | 约定 |
|----|------|
| 位宽 | 数据通路 **8 位**；地址字段 8 位编码 |
| 存储（行为 runtime） | 统一地址空间 RAM `0x00`–`0xFF`（256 字） |
| 存储（教学电路 datapath） | 先用 **16×8**（`0x00`–`0x0F`，`ram_16x8`）；装载越界失败可见 |
| 寄存器堆 | `R0`–`R7`（8×8）；`R0` 兼作累加器习惯用法，无特权 |
| 专用 | `PC`（8）、`IR`（8，操作码字节）、`IMM`/`ADDR`（第二字节锁存） |
| 标志 | `Z`（结果为 0）、`C`（加减进/借位）；条件跳转只看它们 |
| 复位 | `PC=0x00`，标志清 0；RAM/RegFile **不**自动清（装载程序时写入） |
| 控制 | **极简多周期硬布线**（见下）；非流水线、无中断 |

## 指令编码

最多 **2 字节**：

```
字节 0: [ opcode:4 | rd:3 | x:1 ]   多数指令
字节 1: imm8 或 addr8（需要时）
```

- `rd` / `rs`：寄存器编号 0–7  
- 双寄存器指令：字节 0 = `[opcode:4 | rd:3 | 0]`，字节 1 低 3 位 = `rs`（高位忽略）  
- 单寄存器 + 立即数/地址：字节 1 = `imm`/`addr`  
- 无操作数：仅字节 0  

### 操作码表

| opc | 助记符 | 字节 | 语义 |
|-----|--------|------|------|
| `0x0` | `HALT` | 1 | 停机；`halted=1` |
| `0x1` | `NOP` | 1 | 空操作 |
| `0x2` | `LOAD Rd, addr` | 2 | `Rd ← Mem[addr]` |
| `0x3` | `STORE Rs, addr` | 2 | `Mem[addr] ← Rs`（`rd` 字段编码 `Rs`） |
| `0x4` | `LOADI Rd, imm` | 2 | `Rd ← imm` |
| `0x5` | `MOV Rd, Rs` | 2 | `Rd ← Rs` |
| `0x6` | `ADD Rd, Rs` | 2 | `Rd ← Rd+Rs`；更新 Z、C |
| `0x7` | `SUB Rd, Rs` | 2 | `Rd ← Rd−Rs`；更新 Z、C（借位→C） |
| `0x8` | `AND Rd, Rs` | 2 | `Rd ← Rd∧Rs`；更新 Z；C=0 |
| `0x9` | `OR Rd, Rs` | 2 | `Rd ← Rd∨Rs`；更新 Z；C=0 |
| `0xA` | `XOR Rd, Rs` | 2 | `Rd ← Rd⊕Rs`；更新 Z；C=0 |
| `0xB` | `NOT Rd` | 1 | `Rd ← ¬Rd`；更新 Z；C=0 |
| `0xC` | `JMP addr` | 2 | `PC ← addr` |
| `0xD` | `JZ addr` | 2 | 若 Z=1 则 `PC ← addr` |
| `0xE` | `JC addr` | 2 | 若 C=1 则 `PC ← addr` |

未定义 opcode：**显式错误**（仿真报错，不静默当 NOP）。

## 汇编语法（P9）

- 一行一条；`#` 或 `;` 行尾注释  
- 标签：`name:`  
- 寄存器：`R0`…`R7`（大小写不敏感）  
- 立即数/地址：十进制或 `0x` 十六进制  
- 伪指令：`ORG addr`（装载基址）、`DB byte…`（原始数据）  
- 助记符与上表一致；`LOAD R1, 0x10` / `ADD R0, R1` 等形式  

错误必须带**行号**；禁止半成功装载。

## 多周期控制（P7/P8）

每条指令经过有限状态（理想时钟一步一态）：

1. **FETCH0** — `IR ← Mem[PC]`；`PC ← PC+1`  
2. **FETCH1** — 若指令长度=2：锁存第二字节；`PC ← PC+1`；否则跳过  
3. **EXEC** — 译码执行（ALU / 寄存器传送 / 分支目标计算）  
4. **MEM** — 仅 `LOAD`/`STORE`：访存读写  
5. **WB** — 写回 RegFile（若需要）；`HALT` 置位后停在 **HALTED**  

硬布线：状态 + opcode → 控制信号（`PC_inc`、`IR_load`、`RF_we`、`Mem_we`、`ALU_op`、`PC_load` 等）。微码 / 流水线 **不做**。

## 与积木对齐

| ISA 需求 | 积木（P5/P6） |
|----------|----------------|
| 运算与标志 | `alu_8` |
| 通路选择 | `mux_2_1_8` / `mux_4_1_8`、`demux_1_2_8` |
| 比较/零检测可教 | `cmp_8` |
| PC / 暂存 | `reg_8` |
| R0–R7 | `regfile_8x8` |
| 程序与数据 | 行为 runtime：256 字；教学电路：`ram_16x8`；固定查表教具 `rom_16x8`（非可编程） |

## 教学电路模式（datapath canvas）

- 地址有效范围 **`0x00`–`0x0F`**；`JMP`/`LOAD`/`STORE`/`ORG`/`DB` 超出则装载或运行报错  
- 网表协调 PC/IR/RegFile/ALU/Mem/控制；一步一相位（同多周期表）  
- 可下钻到积木 internals；完整 256 字画布 RAM 另起 change

## 验收 demo（P9）

约 10–30 行：`LOADI` 装立即数 → `ADD`/`SUB` → `JZ`/`JMP` 循环 → `STORE` 写回 → `HALT`。

## 明确不做

流水线、中断、特权级、浮点、多核、缓存、完整现代 ISA。
